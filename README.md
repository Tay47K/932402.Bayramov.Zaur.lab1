Лабораторная работа №1. Основы HTML и структура веб-страницы

Вариант №14: Дизайнер и визуализатор
---------------------------Описание
Страница «О себе», выполненная с использованием семантических тегов HTML5.
---------------------------Реализованные элементы
`<header>` — имя студента и заголовок страницы
`<main>` — основной контент с двумя секциями:
- «Навыки» — маркированный список дизайнерских навыков
- «Проекты» — нумерованный список из 4 проектов
`<aside>` — боковая панель с любимыми технологиями и стилем дизайна
`<footer>` — копирайт и год
`<img>` с атрибутами `src`, `alt`, `width`, `height``<form>` обратной связи с полями (`text`, `email`, `textarea`) и кнопкой отправки, у всех полей заданы атрибуты `name` и `placeholder`
----------------------------Цветовая гамма
Пастельно-розовая с контрастными акцентами (`#FDEBF3`, `#E85D9E`, `#C2185B`).
----------------------------Валидация
Код проверен на [W3C Validator](https://validator.w3.org/).
